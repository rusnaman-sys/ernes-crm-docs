Схема воронок
Две воронки продаж AmoCRM — B2B и Госзакупки
Воронка 1 — B2B Продажи
Неразобранные→ Новый лид→ Первичный контакт→ Квалифицирован→ Выезд*→ Тех. расчёт→ КП отправлено→ Согласование→ Подг. договора→ Договор подписан→ Оплата→ Отгрузка→ Монтаж*→ Подп. актов→ ✓ Реализовано
* Выезд на обследование и Монтаж — только если нужны
Воронка 2 — Госзакупки
Тендер найден→ Анализ ТЗ + маржа→ Выезд*→ Подг. заявки→ Заявка подана→ Идёт процедура→ Победа → договор→ Поставка / монтаж→ АВР подписан→ Ожидание оплаты→ ✓ Реализовано
Особые этапы: Отказ от участия Зависший / спорный Закрыто не реализовано
Автоматизация
  • Бот Telegram + goszakup.gov.kz → автоматически создаёт сделку в воронке «Госзакупки» и заполняет все поля
  • При переходе в «Подготовка договора» (B2B) → автоматически создаётся папка Google Диска для клиента
  • Возврат из «Закрыто не реализовано» → реактивация старой сделки, начинается с «Квалифицирован» (B2B) или «Анализ ТЗ» (Госзакупки)
Главные правила
Применяются к обеим воронкам
B2B + Госзакупки
Если действие не в AmoCRM — его не существует
Звонок, переписка, расчёт, КП, документы — всё фиксируется. Нет записи = нет факта = нет бонуса.
1 Одна сделка = один клиентский запрос или один тендер
Дубли запрещены. Повторный тендер или новый проект = новая сделка.
2 Перейти на следующий этап = выполнить условия текущего
Система не пропустит без обязательных полей. Откат назад — только с согласования РОПа.
3 Ни одна сделка не остаётся без активной задачи
После каждого контакта или события — задача с датой. Сделка без задачи = брошенная сделка.

Отказ от участия
Принято решение не участвовать в тендере.
Откуда: Анализ ТЗ + расчёт маржи → не проходим по условиям
Обязательное условие
